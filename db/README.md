# База данных CRM-системы «Тихий час»

Артефакты для раздела 3.2 «Разработка баз данных в среде СУБД» пояснительной записки.

## Файлы

| Файл | Назначение |
|---|---|
| [`schema.sql`](./schema.sql) | DDL-скрипт для MSSQL 2019+. Содержит CREATE TABLE для всех бизнес-таблиц, ограничения (PK/FK/UNIQUE/CHECK), индексы. Таблицы ASP.NET Core Identity не описаны — создаются EF Core миграциями. |
| [`schema.dbml`](./schema.dbml) | Источник ER-диаграммы для [dbdiagram.io](https://dbdiagram.io/d). Импортируется туда, экспортируется PNG/PDF для вставки в раздел 2.3 ПЗ (рисунок 2.1). |

## Использование

### Генерация ER-диаграммы

1. Открыть [dbdiagram.io](https://dbdiagram.io/d) (без регистрации).
2. Создать новый проект.
3. Вставить содержимое [`schema.dbml`](./schema.dbml) в редактор.
4. Экспортировать: `Export` → `to PNG` (для вставки в ПЗ) или `to PDF`.
5. Также можно экспортировать проверочный DDL: `Export` → `to MS SQL` — и сравнить с [`schema.sql`](./schema.sql).

### Применение DDL к локальной MSSQL

```powershell
sqlcmd -S localhost -d BarbershopCrm -i db/schema.sql
```

> В проекте используется EF Core Code-First, поэтому схема БД в продуктиве
> создаётся через `dotnet ef database update`, а этот файл — справочный
> артефакт для ПЗ (раздел 3.2) и для ручной инспекции структуры.
