# Приложение Г
## (обязательное)
### Экранные формы пользовательского интерфейса

В настоящем приложении приведены экранные формы CRM-системы сети барбершопов «Тихий час», реализующие основные пользовательские сценарии: онлайн-запись для гостя, личный кабинет клиента и админ-панель владельца сети. Все экранные формы реализованы на технологии Razor Pages поверх ASP.NET Core 8 с использованием собственной адаптивной дизайн-системы (тёмная премиальная тема).

## Г.1 Гостевая часть сайта

### Г.1.1 Главная страница

Главная страница содержит шапку с навигацией («Услуги», «Мастера», «Филиалы», «Записаться»), герой-блок с краткой презентацией сети и преимуществами (опыт, чистота инструмента, локации), карточки филиалов с адресом и графиком работы, прайс-лист с ценами и длительностями услуг и подвал с контактами. Композиция оптимизирована под десктоп и мобильные устройства (брейкпоинты 768px и 1024px).

### Г.1.2 Каталог услуг

Каталог услуг отображает все активные позиции прайс-листа в виде карточек: название услуги, длительность в минутах, цена в рублях и краткое описание. Из карточки доступен переход к мастеру записи с предзаполненной услугой.

### Г.1.3 Каталог мастеров

Каталог мастеров содержит карточки барберов: фото-аватар, ФИО, должность, дата приёма на работу (стаж в сети), краткая биография и индикатор активности. По клику на карточку открывается детальная страница мастера со списком филиалов, в которых он работает, и услуг, которые он оказывает.

### Г.1.4 Мастер онлайн-записи (5 шагов)

Мастер записи реализован на одной странице (Razor Page `/Booking`) с прогрессом и переходом между шагами без перезагрузки. Основные шаги перечислены в таблице Г.1.

Таблица Г.1 — Шаги мастера онлайн-записи

| Шаг | Содержание                                                                              |
|-----|-----------------------------------------------------------------------------------------|
| 1   | Выбор филиала из списка с адресом и графиком работы                                     |
| 2   | Выбор услуги из активного прайс-листа с указанием длительности и цены                   |
| 3   | Выбор мастера, оказывающего выбранную услугу в выбранном филиале                        |
| 4   | Выбор даты в пределах горизонта планирования (14 дней) и свободного слота (15 мин шаг)  |
| 5   | Ввод имени и телефона гостя, подтверждение записи и отображение номера записи           |

На шаге выбора слота свободные временные интервалы рассчитываются сервисом `BookingService.GetAvailableSlotsAsync` на основании рабочего расписания мастера в филиале и длительности выбранной услуги (с учётом возможного `DurationOverride`).

### Г.1.5 Подтверждение записи

После создания записи пользователю отображается экран с её параметрами: номер записи, дата и время, мастер, услуга, длительность, итоговая стоимость и адрес филиала. На этом же экране размещены контакты для отмены или переноса.

## Г.2 Кабинет клиента

### Г.2.1 Страница входа и регистрации

Аутентификация реализована на ASP.NET Core Identity 8: пара «логин — пароль» с подтверждением e-mail. Поддерживаются роли `Guest`, `Client`, `Master`, `Admin`, `Owner`. Гость превращается в зарегистрированного клиента после регистрации с подтверждением телефона; история его прежних записей по совпадению телефона привязывается к новому аккаунту.

### Г.2.2 История записей клиента

Страница «Мои записи» отображает все будущие и прошедшие записи клиента: дата, мастер, услуга, филиал, статус (`Created`, `Confirmed`, `Completed`, `Cancelled`). Поддерживается отмена будущей записи не позднее чем за 12 часов до её начала.

## Г.3 Админ-панель владельца сети

### Г.3.1 Дашборд

Главная страница админ-панели содержит шесть виджетов с ключевыми показателями за последние 7 дней:

- общее количество записей,
- количество завершённых визитов,
- общая выручка (агрегация на стороне приложения, в рублях),
- средний чек (выручка / количество визитов),
- количество активных мастеров,
- количество активных филиалов.

Виджеты реализованы как Razor-партиалы и подгружаются на странице `/Admin/Index` единым запросом с проекцией данных через EF Core.

### Г.3.2 CRUD-страницы справочников

Для каждой основной сущности (`Branch`, `Service`, `Master`, `Schedule`) реализованы стандартные четыре операции:

- список с пагинацией и фильтрами,
- форма создания,
- форма редактирования,
- удаление с подтверждением и каскадной обработкой связанных записей.

Доступ ко всем CRUD-страницам ограничен ролью `Owner` либо `Admin` соответствующего филиала (для администраторов филиала видимость и редактируемость данных ограничены связью с конкретным `Branch`).

### Г.3.3 Журнал записей

Журнал записей `/Admin/Bookings` отображает все записи в табличном виде с фильтрами по филиалу, мастеру, статусу и диапазону дат. Из строки журнала возможен переход к редактированию записи (изменение статуса, переназначение мастера) и регистрации фактического визита с указанием итоговой суммы.

## Г.4 Дизайн-система

Все экранные формы используют собственную дизайн-систему, не базирующуюся на Bootstrap. Базовые компоненты — кнопки, формы, карточки, таблицы, модальные окна — реализованы в файле `wwwroot/css/site.css` (≈ 800 строк CSS) с использованием CSS-переменных для цветовой палитры и типографики. Тема — тёмная, премиальная, основные цвета: `#0a0a0a` (фон), `#d4af37` (акцент золотой), `#f5f5f5` (текст). Шрифт основного текста — `Inter`, акцентного — `Playfair Display`. Адаптивность реализована через media queries без сторонних фреймворков.
