# 5 Эксплуатационная документация

## 5.1 Руководство пользователя

Настоящее руководство пользователя описывает порядок работы с разработанной системой управления взаимоотношениями с клиентами «Тихий час» для двух категорий пользователей: гостя сервиса (клиент, оформляющий запись на приём) и владельца сети барбершопов (администратор, управляющий справочниками филиалов, услуг, мастеров и журналом записей).

### 5.1.1 Системные требования

Для работы с приложением со стороны пользователя необходимо устройство (персональный компьютер, ноутбук, планшет или смартфон) с установленным современным веб-браузером, поддерживающим стандарт HTML5 и JavaScript ECMAScript 2017. Тестирование проводилось в браузерах Google Chrome 120, Mozilla Firefox 121, Microsoft Edge 120, Safari 17. Минимальное разрешение экрана — 360×640 пикселей.

Для работы серверной части приложения необходимы:
- операционная система Windows Server 2019/2022 либо Linux Ubuntu 22.04 LTS;
- среда выполнения .NET 8 Runtime (ASP.NET Core Runtime);
- система управления базами данных Microsoft SQL Server 2019 или новее (поддерживается также SQL Server Express);
- свободное место на жёстком диске не менее 1 ГБ для приложения и не менее 5 ГБ под базу данных в перспективе на 3 года эксплуатации.

### 5.1.2 Сценарий «Запись на приём»

Сценарий выполняется гостем сервиса без необходимости регистрации учётной записи и состоит из шести шагов.

**Шаг 1.** Перейти на главную страницу приложения по адресу, опубликованному сетью барбершопов «Тихий час». На странице нажать кнопку «Записаться онлайн» либо ссылку «Записаться» в верхнем меню.

**Шаг 2.** На странице «Шаг 01 — Куда вы заходите?» в виде сетки карточек отображаются филиалы сети с указанием часов работы и адреса. Выбрать нужный филиал нажатием кнопки «Выбрать →» в его карточке.

**Шаг 3.** На странице «Шаг 02 — Что делаем?» отображается прайс-лист услуг выбранного филиала. Каждая услуга показана с описанием, длительностью в минутах и ценой в рублях. Выбрать нужную услугу нажатием на её строку.

**Шаг 4.** На странице «Шаг 03 — К кому?» отображаются мастера, оказывающие выбранную услугу в выбранном филиале. Выбрать конкретного мастера либо вернуться к выбору услуги ссылкой «← Другая услуга». При нажатии «Выбрать →» произойдёт переход к выбору времени.

**Шаг 5.** На странице «Шаг 04 — Когда удобно?» в верхней части отображается ряд дат на ближайшую неделю; активная дата выделена бронзовым фоном. В нижней части отображается сетка свободных слотов в формате `HH:MM` с шагом 15 минут. Слоты, перекрываемые существующими записями, перерывами на обед и нерабочим временем мастера, в сетку не включаются. Выбрать удобное время нажатием на слот. При отсутствии свободных слотов в выбранную дату на странице будет показано предупреждение «На эту дату слотов нет, выберите другую».

**Шаг 6.** На странице «Шаг 05 — Как с вами связаться?» в верхней части отображается сводка ранее введённых данных (филиал, услуга, мастер, дата и время). В форме необходимо заполнить поля «Фамилия», «Имя», «Телефон» (поле обязательно) и «E-mail» (поле необязательно). Нажать кнопку «Подтвердить запись».

**Шаг 7.** При успешном создании записи отображается страница подтверждения с уведомлением «Запись подтверждена», номером записи и полным списком её параметров. На этом сценарий завершается.

В случае одновременного оформления записи другим клиентом на тот же временной слот в момент подтверждения сервер вернёт сообщение об ошибке «Запись на это время уже существует». В таком случае необходимо вернуться на шаг 5 ссылкой «← Другое время» и выбрать другой свободный слот.

### 5.1.3 Сценарий «Управление сетью» (роль владельца)

Доступ к разделу управления имеют только пользователи с ролью `Owner`. Учётная запись владельца создаётся при первом запуске приложения и имеет логин, опубликованный отдельно (значение по умолчанию — `owner@tihiychas.ru`, пароль `Owner!2026`, который рекомендуется сменить при первом входе).

**Вход в систему.** Нажать ссылку «Вход» в верхнем меню. На странице входа ввести e-mail и пароль владельца, нажать кнопку «Log in». При успешном входе в верхнем меню появляется ссылка «Админка», переход по которой открывает административную панель.

**Сводка по сети.** На главной странице административной панели отображаются три KPI-карточки с показателями оперативной деятельности (записей сегодня, активных клиентов, выручка за неделю по завершённым визитам) и быстрые ссылки на справочники.

**Управление филиалами.** Перейти по вкладке «Филиалы». В верхней части страницы отображается общее количество филиалов и кнопка «+ Новый филиал». В таблице отображаются все филиалы сети с возможностью изменения и удаления. Удаление филиала разрешено только при отсутствии связанных с ним записей и привязок мастеров; в противном случае на странице удаления выводится сообщение «Удаление невозможно» с указанием количества связанных объектов.

**Управление услугами.** Перейти по вкладке «Услуги». Действия аналогичны вкладке филиалов: создание, изменение и удаление позиций прайс-листа. Длительность услуги должна быть кратна 15 минутам — это требование вытекает из сетки свободных слотов мастера записи.

**Управление мастерами.** Перейти по вкладке «Мастера». Помимо стандартных операций над списком, при создании нового мастера в одной форме заполняются персональные данные (ФИО, телефон, e-mail, пол, дата рождения), профессиональные данные (должность, дата приёма, биография, статус активности) и привязки мастера к филиалам и услугам, в которых он работает. Удаление мастера, на которого оформлены записи, заменяется деактивацией: запись остаётся в базе данных, но мастер исключается из выбора при онлайн-записи. Это сохраняет историю и предотвращает потерю отчётности.

**Управление записями.** Перейти по вкладке «Записи». В таблице отображаются последние 200 записей в обратном хронологическом порядке. Каждая запись имеет статус: «Создана» (сразу после оформления гостем), «Подтверждена», «Завершена», «Отменена», «Не пришёл». В строке записи доступны кнопки изменения статуса в зависимости от текущего: для статуса «Создана» — «Подтвердить» и «Отменить»; для «Подтверждена» — «Завершить» и «Отменить». Запись со статусом «Завершена» учитывается в выручке административной сводки.

**Выход из системы.** Нажать ссылку «Выйти» в верхнем меню. Сессия завершается, ссылка «Админка» в меню исчезает.

### 5.1.4 Возможные ошибки и способы их устранения

В таблице 5.1 приведены типовые ошибки эксплуатации и способы их устранения.

Таблица 5.1 — Типовые ошибки и способы их устранения

| Ошибка                                              | Причина                                                          | Способ устранения                                                            |
|-----------------------------------------------------|------------------------------------------------------------------|------------------------------------------------------------------------------|
| Пустой список филиалов на шаге 1                    | В справочнике филиалов нет ни одной записи                        | Войти в админку под ролью `Owner`, добавить хотя бы один филиал              |
| Пустой список мастеров на шаге 3                    | На указанной паре «филиал × услуга» нет ни одного мастера         | Привязать мастера к филиалу и услуге в редакторе мастеров                    |
| «На эту дату слотов нет»                            | У мастера нет рабочего расписания на дату либо все слоты заняты   | Выбрать другую дату либо другого мастера                                     |
| «Запись на это время уже существует»                | Между загрузкой шага 5 и подтверждением другой клиент занял слот  | Вернуться на шаг 4 и выбрать другой слот                                     |
| HTTP 403 при попытке открыть `/Admin/...`           | Текущий пользователь не имеет роли `Owner`                        | Войти под учётной записью владельца сети                                     |
| HTTP 500 при старте приложения                      | Не запущен экземпляр SQL Server либо неверная строка подключения  | Проверить значение `ConnectionStrings:DefaultConnection` в `appsettings.json` |
