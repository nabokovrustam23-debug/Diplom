# Заключение

В ходе выполнения выпускной квалификационной работы была разработана информационная система управления взаимоотношениями с клиентами для сети барбершопов «Тихий час» с филиалами в Краснодаре и Сочи. В процессе работы решены все задачи, поставленные на этапе формулирования задания.

Проведён анализ предметной области сети барбершопов как объекта информатизации: выявлены ключевые роли (гость, клиент, мастер, владелец, администратор), сценарии взаимодействия между ними и существующие проблемы организации, обусловленные ручным учётом записей на бумаге. Сформулированы функциональные требования к системе, разделённые на семь групп: учёт филиалов, прайс-листа, мастеров, расписаний, гостевая онлайн-запись, личный кабинет клиента и администрирование сети.

Разработана модель данных, включающая одиннадцать сущностей, спроектированных в соответствии с требованиями третьей нормальной формы. Применён паттерн Persona — единая сущность хранения персональных данных, связанная отношением «один-к-одному» с сущностями User, Client и Master. Это решение исключает дублирование персональных данных в разных таблицах и упрощает преобразование роли пользователя в системе (например, переход клиента в роль мастера) без изменения структуры базы данных. ER-диаграмма построена в нотации Crow’s Foot с использованием инструмента dbdiagram.io.

Обоснован выбор средств разработки. По результатам сравнения трёх серверных программных платформ, трёх систем управления базами данных, трёх способов построения пользовательского интерфейса и трёх сред разработки в качестве рабочего стека выбраны: ASP.NET Core 8, Microsoft SQL Server 2019, Razor Pages, Microsoft Visual Studio 2022 Community. Выбор подтверждён сводной таблицей соответствия выбранных средств функциональным и нефункциональным требованиям к системе.

Реализована программная система. Серверная часть выполнена в виде монолитного приложения с трёхслойной структурой исходного кода: Domain (классы предметной области), Infrastructure (доступ к базе данных, аутентификация, сервисы), Web (веб-страницы и пользовательский интерфейс). База данных создана при помощи механизма миграций Entity Framework Core. Реализован модуль гостевой записи на приём, состоящий из мастера в пять шагов; центральный алгоритм расчёта свободных временных слотов вынесен в отдельный сервис `SlotService`. Реализована административная панель для роли владельца сети с CRUD-операциями над филиалами, услугами и мастерами и журналом записей с возможностью изменения их статусов.

Разработан собственный визуальный язык приложения без использования сторонних UI-фреймворков (Bootstrap, Tailwind и т. п.). Применена тёмная цветовая схема с бронзовым акцентом и типографика на трёх шрифтах (Cormorant Garamond, Inter, JetBrains Mono), что соответствует визуальной эстетике премиальной мужской услуги и формирует узнаваемый образ сети.

Проведено модульное тестирование разработанных программных модулей. Реализовано тринадцать автоматизированных тестов, покрывающих ключевые компоненты предметной логики: класс `Persona`, сервис `DatabaseSeeder` и сервис `SlotService`. Все тесты успешно пройдены при последнем прогоне. Дополнительно проведён ручной сквозной тест сценария «гостевая запись», подтвердивший корректность работы системы.

Подготовлена эксплуатационная документация: руководство пользователя для гостя сервиса и владельца сети, перечень типовых ошибок и способов их устранения, список системных требований к развёртыванию.

Разработанная система готова к внедрению в одном из филиалов сети «Тихий час» в режиме опытной эксплуатации. Эффект от внедрения — сокращение трудозатрат администратора на ведение журнала записей, снижение количества потерянных бронирований за счёт автоматического исключения занятых слотов из выбора, формирование цифрового следа взаимодействия с клиентом, который в дальнейшем послужит основой для аналитических модулей.

В качестве направлений дальнейшего развития системы могут быть рассмотрены: реализация модуля автоматических напоминаний клиентам о предстоящем визите по SMS и e-mail, программа лояльности с накопительной системой скидок, мобильное приложение для клиента и мастера на основе того же серверного API, интеграция с онлайн-кассами в соответствии с требованиями 54-ФЗ, а также аналитический модуль с дашбордами по выручке, занятости мастеров и удержанию клиентов.

Цель выпускной квалификационной работы — разработка модулей программного приложения для управления взаимоотношениями с клиентами сети барбершопов — достигнута. Все задачи, сформулированные в задании на выпускную квалификационную работу, выполнены в полном объёме.
