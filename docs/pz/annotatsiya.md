# Аннотация

Выпускная квалификационная работа выполнена по специальности 09.02.07 «Информационные системы и программирование» по теме «Разработка модулей программного приложения для управления взаимоотношениями с клиентами сети барбершопов "Тихий час"».

Пояснительная записка содержит \[листов\] страниц, \[ил\] рисунков, \[табл\] таблиц, \[прил\] приложения, \[N\] использованных источников.

**Объект разработки** — информационная система управления взаимоотношениями с клиентами для сети барбершопов с филиалами в Краснодаре и Сочи.

**Цель работы** — разработка модулей программного приложения, обеспечивающих автоматизацию ведения справочников сети, учёта расписаний мастеров, оформления записей клиентов на приём и управления жизненным циклом записи на стороне владельца сети.

**Задачи работы:** провести анализ предметной области и сформулировать функциональные требования; спроектировать модель данных в третьей нормальной форме; обосновать выбор средств разработки; реализовать серверную часть приложения, гостевой мастер записи и административную панель; разработать собственный визуальный язык приложения; провести модульное и сквозное функциональное тестирование; подготовить эксплуатационную документацию.

**Использованные методы и средства:** ASP.NET Core 8, Razor Pages, C# 12, Entity Framework Core 8, Microsoft SQL Server 2019, ASP.NET Core Identity, xUnit.net 2 с провайдером Microsoft.EntityFrameworkCore.InMemory 8, Microsoft Visual Studio 2022 Community, Git/GitHub, dbdiagram.io. ER-моделирование выполнено в нотации Crow’s Foot. Применён паттерн Persona для устранения дублирования персональных данных между ролями User, Client и Master.

**Полученные результаты:** разработана и протестирована программная система, состоящая из одиннадцати предметных таблиц базы данных, серверной программной части, мастера гостевой записи в пять шагов и административной панели владельца сети с CRUD-операциями над филиалами, услугами и мастерами и журналом записей. Создана собственная дизайн-система без сторонних UI-фреймворков. Реализован сервис расчёта свободных временных слотов, учитывающий рабочее расписание мастеров, перерывы и существующие записи. Все тринадцать автоматизированных модульных тестов успешно пройдены.

**Внедрение:** разработанная система готова к внедрению в одном из филиалов сети «Тихий час» в режиме опытной эксплуатации.
