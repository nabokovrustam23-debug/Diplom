## Запуск и проверка

```bash
dotnet build BarbershopCrm.sln
dotnet test BarbershopCrm.sln
dotnet run --project src/BarbershopCrm.Web
```

По умолчанию приложение запускается на SQLite (`barbershop.db`), чтобы демо и тестирование
работали без локального SQL Server. Целевая СУБД для ВКР — Microsoft SQL Server 2019;
DDL-скрипт и ER-артефакты находятся в [`db/`](db/).
